# appzone Курск — концепт лендинга

Демонстрационная работа для портфолио: концепт-редизайн лендинга магазина техники в Курске.
**Не является официальным сайтом appzone.** Официальный сайт — https://kursk.appzone.store/

Данные (адреса, телефон, цены «от», преимущества) взяты с kursk.appzone.store и из сообщества appzone во ВКонтакте на 26.11.2026.
Иллюстрации техники — авторские SVG без логотипов производителей. Шрифты Onest и Unbounded — OFL-1.1.

Стек: HTML, CSS, JavaScript без библиотек.
